# podu-dev/.github

The organisation profile and default community files for [Podu](https://www.podu.dev): free subdomains for developers.

- `profile/README.md`: the page shown on [github.com/podu-dev](https://github.com/podu-dev)
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`: defaults for every Podu repo that doesn't have its own
