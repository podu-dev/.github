## What Podu is

Podu gives every developer a short, free address for their projects:

```
alice.podu.dev
portfolio-by-sam.podu.dev
weather-api.podu.dev
```

Podu doesn't host your site. It points a clean name at wherever your project already lives. In Romanian, *podu'* means "the bridge", and that's the whole idea: a bridge between your name and your work.

## How it works

1. **Claim.** Sign in with GitHub and pick a free name.
2. **Point.** Choose your host and paste your project address. Podu creates the DNS records for you.
3. **Live.** About a minute later your pod answers. Change or delete it any time from **My Pods**.

| Host | Record Podu creates |
|---|---|
| Vercel, Netlify, Render, Cloudflare Pages, GitHub Pages | `CNAME` |
| Your own server | `A` (IPv4, up to 2) |
| Email provider | `MX` |
| Host verification | `TXT` |

## The deal

- **Free forever.** No paid tiers, no ads.
- **Any host.** Your code stays where it is.
- **Safe by default.** `.dev` is HTTPS-only, every claim passes automatic safety checks, and phishing is taken down fast.
- **Open.** Every pod is a public record.
