# Contributing to Podu

Thanks for helping. Podu is a small, free project, so clear and careful changes matter more than big ones.

## Before you start

- For anything bigger than a typo, open an issue first so we can agree on the approach.
- Read the repo's own README for setup and tests.
- Be kind. This project follows the [Code of Conduct](CODE_OF_CONDUCT.md).

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Keep the change focused: one fix or feature per pull request.
3. Add or update tests. Pull requests that change behaviour without tests won't be merged.
4. Run the checks before you push: `npm run lint`, `npm run typecheck`, `npm test`.
5. Describe what changed and why in plain words.

## Reserved and blocked names

The list of reserved names is part of the code, so anyone can suggest changes by pull request. Explain why a name should be added, freed, or moved between "never", "on request" and "open".

## Security issues

Don't open public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).
